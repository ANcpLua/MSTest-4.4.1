# OTLP test input contracts

These OpenTelemetry protocol definitions are copied from the qyl collector's
vendored OpenTelemetry proto set. Their Apache-2.0 notices remain in each file.
They are compiled by Grpc.Tools with service generation disabled; Google.Protobuf decodes
real exporter requests. The tests do not search raw protobuf bytes for strings.

Trailing whitespace and line endings are normalized; schema declarations are unchanged.
